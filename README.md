# ใบขอวัสดุปรับปรุงดิน KA

เว็บ React สำหรับกรอกฟอร์ม "หนังสือแสดงความประสงค์ขอรับวัสดุปรับปรุงดิน KA" แล้วออกเป็นไฟล์ PDF
4 หน้าติดกัน หน้าตาเหมือนฟอร์มต้นฉบับทุกประการ พร้อมพิมพ์และเซ็นด้วยปากกา

ขั้นตอนการใช้งาน: **กรอก 5 สเต็ป → ตรวจทาน (สรุปข้อมูล + ตัวอย่าง PDF จริง) → ดาวน์โหลด PDF**

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์สำหรับ deploy ลง dist/
npm run lint
```

## เอกสาร 4 หน้า

| หน้า | ชื่อเอกสาร | ขนาด |
|---|---|---|
| 1 | หนังสือแสดงความประสงค์ขอรับวัสดุปรับปรุงดิน KA | A4 แนวตั้ง |
| 2 | หนังสือสัญญาแสดงความยินยอม | A4 แนวตั้ง |
| 3 | แผนที่แสดงพื้นที่ขอรับวัสดุโดยสังเขป | A4 แนวตั้ง |
| 4 | เอกสารแนบ กฎระเบียบการขนส่งน้ำ KA | A4 แนวนอน |

ข้อมูลผู้ขอและข้อมูลบัตรประชาชนกรอกครั้งเดียว ระบบเติมให้เองทั้งหน้า 1 และหน้า 2
เส้นลายเซ็นเว้นว่างไว้เซ็นด้วยปากกา แต่ชื่อในวงเล็บ `(...)` ใต้ลายเซ็นถูกพิมพ์ให้อัตโนมัติทุกจุด
หน้า 4 เป็นเอกสารแนบข้อความคงที่ จึงไม่มีช่องที่ต้องกรอก

## วิธีที่ใช้สร้าง PDF

โหลด `public/template.pdf` (ไฟล์ฟอร์มต้นฉบับ) ขึ้นมาแล้ววาดข้อความทับด้วย `pdf-lib`
จึงได้หน้าตาตรงกับต้นฉบับ 100% โดยไม่ต้องจัด layout ใหม่

**ข้อควรรู้เรื่องภาษาไทย:** `page.drawText()` ของ pdf-lib ทิ้งค่า GPOS ที่ fontkit คำนวณไว้
วรรณยุกต์ที่ตามหลังสระบนจึงกินความกว้างเกินและเกิดช่องว่างแทรก (เช่น `หมู่ที่` กลายเป็น `หมู่ที ่`)
`src/lib/pdfBuilder.js` จึงไม่ใช้ `drawText` แต่ shape ข้อความเองด้วย `fontkit.layout()`
แล้ววาง glyph ทีละตัวด้วย `Tm` ลง content stream — **ถ้าจะแก้โค้ดวาดข้อความ ต้องคงวิธีนี้ไว้**
(ฟอนต์ต้อง `embedFont(..., { subset: false })` เพื่อให้รหัสใน Identity-H ตรงกับ glyph id เดิม)

## โครงสร้างโค้ด

```
src/
  App.jsx                  สลับหน้า form / preview, กู้ร่าง, สั่งสร้าง PDF, ดาวน์โหลด
  data/schema.js           โครงข้อมูลฟอร์ม ตัวเลือกทั้งหมด และข้อมูลตัวอย่าง
  data/coordinates.js      พิกัดทุกช่องกรอกบนเทมเพลต (ดู "การจูนพิกัด" ด้านล่าง)
  lib/pdfBuilder.js        แปลงข้อมูลฟอร์ม -> PDF 4 หน้า (โมดูลบริสุทธิ์ ใช้ได้ทั้งเบราว์เซอร์และ Node)
  lib/validation.js        ตรวจข้อมูลก่อนอนุญาตให้ไปหน้า Preview
  lib/thai.js              เดือนไทย, ตรวจ checksum เลขบัตร, จัดรูปวันที่ พ.ศ.
  lib/storage.js           เก็บร่างอัตโนมัติ
  components/              FormWizard, Steps, Fields, PreviewPanel
```

### เก็บข้อมูลหลังบ้านในอนาคต

ข้อมูลฟอร์มทั้งหมดเป็นออบเจ็กต์ JSON ก้อนเดียว (รูปแผนที่แยกเป็น data URL ต่างหาก)
และการเก็บร่างถูกรวบไว้ที่ `src/lib/storage.js` เพียงไฟล์เดียว
ถ้าจะย้ายไปเก็บบนเซิร์ฟเวอร์ ให้เปลี่ยนแค่ `saveDraft` / `loadDraft` / `clearDraft`
เป็นการเรียก API — ส่วน UI และตัวสร้าง PDF ไม่ต้องแก้

## การจูนพิกัด (ทำเมื่อฟอร์มต้นฉบับเปลี่ยน)

พิกัดใน `src/data/coordinates.js` ไม่ได้เดาจากตาราง แต่ดึงจากตำแหน่งจริงของ "จุดไข่ปลา"
และกล่องติ๊กในเทมเพลต ต้องมี Python + `pymupdf`

```bash
python devtools/dump-blanks.py 1      # ช่องจุดไข่ปลาของหน้า 1 พร้อมข้อความที่อยู่ข้างหน้า
python devtools/dump-boxes.py  1      # กล่องติ๊กและกรอบใหญ่ของหน้า 1
python devtools/dump-spans.py  1      # ข้อความทั้งหน้าพร้อม bbox (ใช้เมื่อต้องดูละเอียด)
```

ตรวจผลลัพธ์เร็วๆ โดยไม่ต้องเปิดเบราว์เซอร์ — สคริปต์นี้เรียก `src/lib/pdfBuilder.js` ตัวเดียวกับที่แอปใช้

```bash
node devtools/fill-sample.mjs                                   # -> devtools/out.pdf
python devtools/render_pages.py devtools/out.pdf devtools/out 2.0  # -> devtools/out-1..4.png
```

`devtools/render-grid.mjs` วางตารางพิกัดทับเทมเพลตไว้ใช้เทียบด้วยตาเมื่อจำเป็น
